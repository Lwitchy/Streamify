Privacy and external services

Local analysis sends nothing. Text lookup sends title and artist hints to MusicBrainz and Apple. Streamify creates fingerprints locally; AcoustID receives only a fingerprint and duration, never audio. Free AcoustID use is non-commercial and rate limited.

Soulseek account

Soulseek is a peer-to-peer network where people share their own music files, usually properly tagged and at high bitrates. An account is free — you just pick a username and password at slsknet.org. A configured account is required before Streamify can search or download music.

What connecting does Signing in keeps a connection open to the Soulseek network and, as the protocol requires, listens on TCP port 2234 for incoming peer transfers. Streamify shares no folders, but only enable this on a network you trust. Your password is stored on this server so it can reconnect automatically.

Where downloads are saved

Downloads go into a Streamify Downloads folder inside your first configured music directory, so they are picked up by the normal library scan. Change the music directory under Account.

Telemetry & Analytics

We collect listening behavior to calculate your top artists and genres, this data will be used to provide data for next updates like "monthly rewraps".
You can disable it whenever you want.

Allow Analytics Collection If disabled, we will stop tracking your listening habits.

Download Your Data

You can request a copy of your listening history and calculated statistics at any time. The file will be exported in JSON format.

Album Art

Discord loads cover images from its own servers, so it cannot see artwork stored on your machine or LAN. Streamify first reuses an existing public cover, then follows the lookup policy you choose below. Uncertain matches always use the Streamify logo.

Artwork policy
Why every local cover cannot be used

Discord fetches image URLs from the public internet; it cannot read files from this computer. Online modes send track metadata only when no usable public cover exists. YouTube search uses no account, cookies, audio streaming or downloading. Apple-only never contacts YouTube. Successful matches are cached for 30 days.

Public server address

If this Streamify server is reachable from the internet over HTTPS through a reverse proxy or tunnel, enter its address. Discord can then show the exact embedded or uploaded cover without searching another service. This setting affects every user.

Automatic updates

Streamify checks its GitHub releases for a newer version and downloads it in the background. Nothing is installed while you are using the app — the update is applied the next time Streamify quits, or immediately if you press Restart and install.

Check for updates automatically Applies to this server for everyone. When off, Streamify never contacts GitHub on its own.
